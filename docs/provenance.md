# Provenance

z80-rust-fast is a Rust transcription of z80-python (module for module; the
reference pin is `b59c80b`, `b62891b` before the history rewrite). It inherits z80-python's verdicts: see
z80-python's `docs/provenance.md` (audit of 2026-11-13, wave 1), in short
clean, with citations owed for the SingleStepTests generator (MIT) and its
ares (ISC) lineage. This file covers only what this repository adds. No GPL or
LGPL source was opened for this audit.

| Part | Source | Licence | Verdict |
| --- | --- | --- | --- |
| `src/*.rs` core modules | transcribed from z80-python's modules (each file says which) | MIT (ours) | clean (inherits) |
| `src/access_timing.rs` | generated by `scripts/gen_access_timing.py` from z80-python's `_access_timing.py`, itself derived from the SingleStepTests corpus | MIT | **cite**: add "SingleStepTests, MIT, (c) 2024 SingleStepTests" to the generated header, as owed in z80-python |
| `src/bin/z80-fuse.rs` | transcription of z80-python's `validation/fuse_runner.py`, whose docstring says its conventions are "those of FUSE's `coretest.c`" | FUSE GPL-2.0 (format only) | **unclear** (low risk), inherited: settled as in z80-python |
| `src/bin/z80-z80test.rs`, `z80-vectors.rs`, `z80-trace.rs`, `z80-timing.rs`, `src/conformance.rs`, `src/trace.rs` | own runners for the fetched oracles and z80-python's trace schema | ours | clean |
| `tests/data/*`, `conformance/*` | copies of z80-python's example manifests and traces (MIT, named in `tests/data/README.md`) | MIT | clean |

history).
